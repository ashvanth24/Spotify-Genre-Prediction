# Spotify Exploratory Data Analysis (EDA)

## Project Overview

This project performs Exploratory Data Analysis (EDA) on Spotify music data to uncover patterns, trends, correlations, and key influencing factors using statistical summaries and visualization techniques.

The dataset contains various Spotify audio features such as:
- Popularity
- Danceability
- Energy
- Loudness
- Speechiness
- Acousticness
- Instrumentalness
- Liveness
- Valence
- Tempo
- Duration
- Genre

The main objective of this project is to analyze Spotify music characteristics and generate meaningful insights through data exploration and visual storytelling.

## Objectives

- Analyze Spotify music data
- Perform statistical summary analysis
- Identify correlations between audio features
- Discover patterns and trends in music characteristics
- Visualize data using multiple visualization techniques
- Interpret findings through analytical insights

## Key Findings

- Most Spotify songs fall within moderate popularity ranges.
- Danceability and energy are dominant characteristics in modern music.
- Energy and loudness showed strong positive correlation.
- Acousticness negatively correlated with energy and loudness.
- Moderate tempo songs are more common than extremely slow or fast tracks.
- Non-explicit songs dominate the dataset.
- Genre distributions are uneven across Spotify music collections.
- Musical positivity (valence) often increases alongside energy.
